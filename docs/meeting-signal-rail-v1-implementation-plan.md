# 会议录音棚信号条 V1 Implementation Plan

状态：active

日期：2026-08-07

## 1. 目标

在不改会议业务链路的前提下，将独立 `meeting-companion` 窗口从动漫媒体舞台替换为 `320 x 64` 录音棚信号条胶囊。

## 2. 实施步骤

1. 新增信号状态映射和 WebGL 渲染组件，接入现有 `meeting:audio-level`。
2. 改造 `MeetingCompanion` 紧凑布局，保留计时、命令防重、错误恢复、拖动和位置锁定。
3. 将更多操作和停止确认改为胶囊内联模式。
4. 调整 Rust 窗口几何及位置单元测试。
5. 更新五种语言的胶囊名称、状态和控制文案。
6. 运行定向测试、TypeScript、生产构建、MSVC Rust 检查和 Windows 冒烟。

## 3. 验证边界

- 自动验证确认类型、状态映射、IPC 控制契约、窗口几何和构建。
- Windows 人工验证确认透明边缘、真实音量、按钮可用性、拖动吸附和完成 / 失败销毁。
- 现有桌宠素材只做保留性检查，不再作为当前 UI 验收项。

## 4. 回退

- WebGL 失败时使用 DOM 静态刻度，不回退动漫桌宠。
- 展示层异常不得改变会议后端状态；用户始终可回主会议页控制。
