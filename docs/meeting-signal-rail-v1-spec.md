# 会议录音棚信号条 V1 Spec

状态：approved for implementation

日期：2026-08-07

任务等级：Level 2

## 1. Scope Authority（范围权威）

- 本文档替代 `docs/meeting-companion-v1-spec.md` 中的动漫桌宠视觉、媒体素材和 `240 x 232` 窗口规格。
- 会议业务状态机、暂停 / 继续 / 停止、停止确认、时长、错误恢复、拖动、吸附和位置记忆继续复用现有实现。
- 会议录音、ASR（语音转文字）、实时转写、总结、音频保留和历史记录链路不改。
- 普通短口述 `capsule` 窗口不改；会议继续使用独立 `meeting-companion` 窗口。
- 关联计划：`docs/meeting-signal-rail-v1-implementation-plan.md`。
- 关联验收：`docs/meeting-signal-rail-v1-acceptance-checklist.md`。

## 2. 用户可见形态

- 窗口固定为 `288 x 82` logical pixels（逻辑像素），透明、无边框、置顶、不进任务栏。
- 主视图为上下两层：上层显示会议状态与真实音量信号条，下层显示已录时长、暂停 / 继续、结束和更多入口。
- 视觉采用录音棚电平表语言：深色中性底、绿色 / 黄色 / 红色动态刻度，不使用角色、插画或装饰性渐变。
- 控件始终可见，不依赖悬停才出现；文字、图标和最长时长不得挤压或改变窗口尺寸。
- “整理”是停止后的自动状态，不新增独立整理按钮。

## 3. 状态表现

| 状态 | 信号条 | 信息与操作 |
| --- | --- | --- |
| `idle` | 低幅校准脉冲 | 显示“准备录音”与时长 |
| `recording` | 真实 RMS 音量驱动，攻快释慢 | 显示“录音中”、暂停、结束 |
| `quiet` | 信号自然收低但保持底噪刻度 | 显示“环境安静”、暂停、结束 |
| `paused` | 冻结最近信号并转为琥珀色 | 显示“已暂停”、继续、结束 |
| `processing` | 信号向中央汇聚 | 显示“正在整理”，不可重复停止 |
| `completed` | 绿色完成扫光 | 显示“整理完成”，按既有 3 秒规则隐藏 |
| 错误叠加 | 红色警示 | 保留录音状态或整理状态，并提供可执行入口 |

## 4. 交互

- 信号条和状态 / 时长区域可直接拖动窗口；锁定位置后禁止拖动。
- 主操作使用图标按钮并提供 tooltip（工具提示）和可访问名称。
- “更多”与右键打开同一套胶囊内联操作，不使用超出 `82px` 窗口的浮层菜单。
- 停止操作切换为胶囊内联确认，支持 `Escape` 取消、键盘焦点循环和重复点击保护。
- 隐藏 / 关闭仅隐藏窗口，绝不停止会议；打开会议、锁定位置继续复用现有 IPC（进程间调用）。

## 5. 渲染与性能

- 信号条使用 WebGL + GLSL，与现有 `SiriGL` 属于相同技术路径，但保持会议组件独立，不建立皮肤插件系统。
- 沿用现有最多 `10Hz` 的 `meeting:audio-level` 事件；渲染层在本地平滑，不提高 recorder（录音器）上报频率。
- 动画上限约 `30fps`，限制设备像素倍率；隐藏或卸载时取消动画帧并释放 WebGL 资源。
- WebGL 不可用时回退为静态 DOM 刻度，会议控制仍完整可用。
- reduced motion（减少动态效果）时使用稳定的低动态信号，不持续播放装饰动画。

## 6. 不要改动项

- 不重构 ASR provider、录音回调、实时转写、润色、插入或历史主链路。
- 不删除或覆盖现有会议桌宠 WebM、poster、manifest 和校验脚本。
- 不新增皮肤选择器、尺寸设置、下载器、动画依赖或第二套会议状态。
- 不复用短口述 `capsule` 窗口，不改变普通语音胶囊外观。

## 7. 验收标准

1. 会议悬浮窗为 `288 x 82`，录音中可看到真实音量变化，时长和直接控制位于音量条下方。
2. 暂停冻结信号且计时停止；继续后信号和计时恢复；停止仍需二次确认。
3. 停止后自动进入整理态；完成与失败继续遵守既有显示、打开会议和销毁规则。
4. 更多操作、右键、拖动、吸附、位置锁定、隐藏和恢复均在紧凑窗口中可用。
5. WebGL 失败或 reduced motion 不影响会议控制，隐藏后不继续消耗动画资源。
6. 五种语言 key 完整；TypeScript、生产构建、会议定向测试和 MSVC `cargo check` 通过。
7. Windows 人工验证录音、安静、暂停、继续、停止、整理、完成 / 失败和多屏位置恢复。
